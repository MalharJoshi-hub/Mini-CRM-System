2. ARCHITECTURE LAYERS BREAKDOWN
--------------------------------------------------------------------------------
• Layer 1: Authentication & RBAC (lib/auth.js, pages/api/auth/*)
  - Salted bcrypt hashing (10 work factor rounds)
  - Stateless HMAC SHA-256 JWT token generation & verification
  - Role-based authorization guard (Admin, Manager, Agent, User)
  - Request-level header inspection & sanitization

• Layer 2: Persistence & Data (lib/db.js, db/schema.sql, db/seed.sql)
  - PostgreSQL 16 relational engine with managed connection pool (pg.Pool)
  - Parameterized SQL statements eliminating SQL injection vulnerabilities
  - Relational tables: users, customers, interactions, followups, audit_logs
  - Foreign key cascades and performance indexes on email, status, and dates

• Layer 3: API & Intelligent Decision Engine (pages/api/*, lib/decisionEngine.js)
  - 18 RESTful serverless endpoints for CRUD, touchpoints, and analytics
  - AI Decision Engine computing churn risk (0-100%) and priority scores
  - 5-Tier intervention matrix: CRITICAL, HIGH, MEDIUM, LOW, SAFE
  - Background automation worker via node-cron (runScheduler.js)
  - Transactional email dispatching and templating (lib/mailer.js)

• Layer 4: Presentation & UI (pages/*.js, Next.js 16, React 19)
  - Executive KPI Intelligence Cockpit (pages/dashboard.js)
  - Single-click intervention action triggers (Call Done, Email Sent)
  - Customer directory and search filtering (pages/customers.js)
  - Customer 360 profile and touchpoint timeline (pages/customer/[id].js)
  - WCAG-compliant responsive dark/light UI theme system
